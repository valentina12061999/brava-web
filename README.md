# Brava Growth Studio

Website for [bravagrowthstudio.com](https://bravagrowthstudio.com): retention, lifecycle & CRM marketing for independent ecommerce brands in beauty, wellness and fashion.

- Single-page site: everything (copy in English and Spanish, styles, logo and images) lives in `index.html`.
- Hosted on Netlify, which redeploys automatically on every push to `main`.
- The contact form uses Netlify Forms.
